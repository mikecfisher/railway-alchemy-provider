# Support

This project is community-maintained on a best-effort basis.

Use [GitHub Issues](https://github.com/mikecfisher/railway-alchemy-provider/issues)
for reproducible bugs and focused usage questions. Include:

- provider, Alchemy, Effect, Bun, and Node versions;
- operating system;
- Railway token type without the token value;
- whether the service was created or adopted;
- the relevant sanitized error and the smallest stack example.

Do not post credentials, variable values, `.alchemy` state, or private Railway
responses. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Feature proposals should explain the Railway object, its ownership/deletion
semantics, and how live drift can be observed safely.
